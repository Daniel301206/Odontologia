# Imágenes de la interfaz

La carpeta no contenía imágenes al iniciar la Fase 1. Para reemplazar los marcadores visuales, añade:

- `consultorio.jpg` para la tarjeta de atención cercana en `index.php`.
- `equipo.jpg` para la tarjeta del equipo profesional en `index.php`.
- `servicios.jpg` para la tarjeta de servicios en `index.php`.
- `login.jpg` para el encabezado visual de `auth/login.php`.

Los comentarios en las vistas indican dónde conectar cada archivo cuando esté disponible.
